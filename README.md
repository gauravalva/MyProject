# Dr. Rakshith Shetty - Professional Website

A warm, professional one-page introduction website for Dr. Rakshith Shetty, MD (Internal Medicine), Consultant Physician and Diabetologist in Bengaluru, India.

## Features

- **Professional Design**: Warm pastel colors with soft edges and friendly rounded fonts
- **Mobile Responsive**: Optimized for all device sizes
- **Interactive Elements**: Smooth animations, hover effects, and engaging user interactions
- **Patient-Focused**: Testimonials, awards, and clear contact options
- **Accessibility**: Keyboard navigation support and proper ARIA labels
- **Performance**: Optimized loading and smooth scrolling

## Sections

1. **Hero Section**: Professional photo, name, title, and warm introduction
2. **About Doctor**: Comprehensive background, languages, and location
3. **Contact & Social**: WhatsApp, Practo, Instagram, and LinkedIn links
4. **Testimonials**: Patient reviews in attractive card format
5. **Awards & Recognition**: Kempegowda Award and professional memberships
6. **Professional Experience**: Hospital affiliations and career highlights
